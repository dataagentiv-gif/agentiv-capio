# Aturan kerja CAPIO

Untuk pekerjaan ekstraksi referensi, template, caption, motion, atau efek visual,
wajib membaca [docs/ATURAN_EKSTRAKSI_TEMPLATE.md](docs/ATURAN_EKSTRAKSI_TEMPLATE.md) sebelum
mengubah preset atau renderer. Ikuti klasifikasi, rumus, kontrak renderer,
format brief, dan pemeriksaan visual di dalamnya sesuai ruang lingkup tugas.

Gunakan `docs/template.md` untuk kontrak template pada branch yang menyediakannya.
Panduan ekstraksi berisi aturan dan nilai referensi hasil fitting; keberadaannya
tidak berarti semua kemampuan tersebut sudah diimplementasikan pada branch ini.
Nilai referensi bukan default universal dan bukan setting editor asli.

Instruksi pengguna menentukan ruang lingkup. Jangan menyalin prototype engine,
cue demo, media hasil, cache, atau dependensi dari folder referensi hanya untuk
menambahkan aturan ekstraksi.
